# Chirayu Website

Chirayu Health Awareness & Research Centre - Official Website

A modern, responsive website built with Next.js for Chirayu Health Awareness & Research Centre, a community-focused health organization in Dharwad, Karnataka.

## Features

- Modern, clean design with Tailwind CSS
- Responsive layout for all devices
- Health awareness programs showcase
- Community health screening information
- Volunteer and donation sections
- Contact and partnership information

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Build

```bash
npm run build
npm start
```
